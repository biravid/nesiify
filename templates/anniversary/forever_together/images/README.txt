# Custom Images Folder

Place your own images here to personalize the website!
The website is pre-configured to look for the following filenames:

1. `hero.jpg` - The main background image for the top screen.
2. `photo1.jpg` to `photo8.jpg` - Eight images used in the interactive Memory Wall and the Masonry Grid Gallery.

### Auto-Fallback System:
If you don't have these images or leave them missing, the website will AUTOMATICALLY detect it and render a gorgeous, premium animated CSS gradient placeholder instead. You can deploy and test it right away!
